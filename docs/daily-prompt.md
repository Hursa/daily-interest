# 每日生产指令

定时任务每天 07:04(台北)读这份文件并照做。改生产行为改这里,**不用动网页端的任务配置**。

契约在 `docs/contract.md`,**那份是唯一权威**,本文件只讲怎么执行。冲突时以契约为准。

---

## 0 · 准备

```bash
git clone "https://x-access-token:${GH_PAT}@github.com/Hursa/daily-interest.git" /tmp/di
```

`GH_PAT` 从环境变量读。没有就停下来报错,**不要把 token 写进任何文件或 commit**。

先完整读一遍 `docs/contract.md`。

## 1 · 避重

读 `manifest.json` 的 `days`,取最近 14 天的 `discover/*.json`,把里面所有 `id`、`title`、
`_facts[].claim` 过一遍。**今天的选题不能和这些重复**,也不要换个说法讲同一件事。

## 2 · 选题:4 条

**不要新闻。**这一页要的是长期成立的东西——一种活法、一门手艺、一个还在运转的老物件、
一次极限处境、一部电影里的人怎么过日子。今天发生的事明天就过期,不是这里的素材。

硬性配比(契约第三节):

- `scope`:`深圳`/`连州`/`西安`(最内圈,你生活过的地方)、`中国`、`全球`。
  **不要求每天集齐,但一周内最内圈至少两条。**排今天之前先看看本周已经有几条
- `category`:`elsewhere`/`limits`/`twohours`/`mastery`/`stillrunning`,**4 条尽量不重复**
- `tone`:`质朴`/`有力`/`欢快`/`独特`,**每天至少一条 `欢快`**
- 第 4 条是备胎(用户点「这条不对」时顶上),质量标准和前三条一样

## 3 · 写

每条按契约第三节的字段写全。几个容易错的:

| | |
|---|---|
| `title` | 8–18 字,**不要把 `［深圳］` 写进去**,那是 app 用 `scope` 拼的 |
| `thesis` | 20–40 字,**是论点不是摘要**。「城中村消失的速度和一个人重建生活的速度不匹配」✅ / 「本文讲述白石洲拆迁后原住户的去向」❌ |
| `body` | 280–450 **汉字**(不含标点和西文),段间 `\n\n`,不要 markdown |
| 结尾 | **最后一句必须是可核实的事实。不抒情,不给教训,不升华。** |
| `id` | kebab-case,**跨天全局唯一**,app 靠它记「看过/否掉」 |
| `_facts` | 每条 claim 配一个**能点开的 URL**,不确定的数字宁可不写 |

### `tryThis`:一天最多一条,可以是零条

> 三条建议是三笔欠账,一条是一个邀请。

**判据:做完之后,它能从你脑子里消失吗?**

不合格的四种形状:

- **跨时间**——「这周」「接下来三天」,没有终点
- **要留意**——「观察一下」「注意看看」,占用持续注意力
- **等结果**——「然后看看会发生什么」,你会一直挂着
- **要约人**——依赖别人的日程,立刻变成待办

判据不是耗时长短:「坐地铁到没下过的站走两小时」合格(一次做完的一整段);
五分钟的「这周每天…」不合格。

**只有当天某条自己长出一个动作时才给。长不出来就空着,那天零条,不解释不道歉**
——写一句「今天没有建议」本身就是噪音。

## 4 · 配图

默认外链,首选 Wikimedia Commons(`https://commons.wikimedia.org/w/api.php`)。
**不要把图存进仓库**——git 历史永远不会缩,一年 350MB 且删了拿不回空间。

许可不限(CC BY / CC BY-SA 都能用),署名不需要显示,但**照旧写进 `_imageCredits`**。
理由和边界见契约「图片署名:不做」那一节。

每张图提交前必须过三关:

1. `curl -sI` → **200 且 `content-type: image/*`**
2. 转灰度后**标准差 ≥ 6**。下载失败常常返回一张纯色图,这条专门挡它
3. 同一条里的图两两做 **dhash 汉明距离**,**< 25/256 判为同一张的不同裁切,换掉**。
   参考:随机两张图约 128,同一张的裁切通常 < 25

### 第四关:人看一眼

**上面三条是机器检查,挡不住「图和文章无关」。**把当天所有图拼成一张联络表,
自己看一遍再发。2026-08-05 那批就是这么抓出两张的:Concordia 首图原本是一间贴着
ESA 横幅的室内办公室,大芬第二张原本是城中村航拍——两张都过了机器检查,但都撑不起正文。

## 5 · 提交

**顺序是硬的**(契约第二节):

1. 写 `discover/<今天>.json`
2. `git add` 它
3. **然后**改 `manifest.json`:`days` 头部插入今天;`discover/` 只留最近 90 天,
   超出的从 `days` 摘掉并删文件
4. **一次 commit 同时包含两者**,再 push

顺序反了会出现「manifest 说有今天,但文件还没推上去」的窗口,app 会拉到 404。
一次 commit,git 的原子性就兜住了。

## 6 · 发完自查

对照契约逐条核:字数区间、`scope`/`category`/`tone` 取值合法、`tryThis` ≤ 1 条、
至少一条 `欢快`、`id` 不与历史重复、`inlineImages[].after` 不超过段数、
`_facts[].source` 都是 URL、末句是事实。

**任何一条不过就地修掉再推,不要留着下次说。**
